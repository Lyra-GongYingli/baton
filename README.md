# Baton

AI 时代的多线程任务接力工具（自用 MVP）。

同时推进好几件事、在多个 AI 和软件之间来回切换时，用它记住每个任务**做到哪、下一步做什么、提示词怎么写、上一步的结果在哪**。

## 结构

**项目 → 任务 → 子任务 → 子子任务**

- **项目**：一块大的事，比如「Moras」。点名字可以改名，点色块可以换颜色。
- **任务**：项目里要推进的一件事，有自己的提示词和状态（待办 / 进行中 / 已暂停 / 已完成）。状态**跟着子任务的进度自动走**：子任务都没开始是待办，有在做、交给 AI 或完成了一部分是进行中，全部完成是已完成；已暂停是手动设的，不会被自动改。手动标成已完成时，下面的子任务会一起打勾。里面是一个子任务 list。
- **子任务**：任务里的具体一步，编号 S1、S2…（排序变了编号也不变），带一段提示词，分给一个执行者：**Claude、Codex、Muse，或者你自己（猫咪）**。状态是 待办 / 我在做 / AI 在跑 / 完成，点圆点切换。
  - **接力子任务**：圆形节点，和上一个用实线连着，上一个完成后才轮到它（没完成时显示「等 Sx 完成」，分给谁都先排队）。
  - **独立子任务**：方形节点，和上一个断开，随时可以做。
  - 两个子任务之间的连接处点一下，就能接上或断开。
- **子子任务**：挂在子任务下面的清单（S1.1、S1.2…），勾选框 + 标题 + 提示词。子任务右侧的「＋」可以连续加。
- **拖动换位置**：子任务和子子任务都能按住拖。上下拖换位置；拖的时候**往右挪**就放进上面那个子任务、变成它的子子任务，**往左挪**就提出来变成子任务（会拿到新的 S 编号）。带着子子任务的子任务拖动时，子子任务跟着走，但它不能再被放进别的子任务里（最多两层）。拖动时有一条插入线，告诉你松手后落在哪一层。
- **提示词**：每一层都能写，点一下就地编辑，双击复制；右上角的小图标点一下也能复制，按住还能直接拖进 AI 的输入框。可以写 `{{目标}}`，复制时换成任务目标。

## 视图

- **项目视图**：项目一组一组排开，任务卡夹在洞洞板上。项目、任务都能按住拖动排序，任务可以拖到别的项目里。
- **月历**（侧边栏的第二个标签）：子任务安排在哪天做。上面是一个月的格子，每天显示排在这天的子任务（项目颜色 + 标题，做完的划掉），滚动时一直钉在顶上；点一天，下面列出这天的子任务，再下面是还没排日子的「待安排」。**按住拖到某一天就排到那天**，格子里的条也能拖到别的日子，拖回「待安排」就取消安排。清单里点一下打开任务，双击复制提示词。
- **晾衣绳（进程）**：点把手上方的小圆钮（侧边栏开着时点右上角同样的图标），屏幕顶上会垂下一根绳子，Claude、Codex、Muse、我（还有「等人领」）各一张卡片夹在上面，写着 TA 在跑什么、排着什么，最左边的牛皮纸吊牌是总数。**点一行复制提示词**（卡片下面冒出「✓ 已复制」），双击打开这个任务，按住拖到别的卡片上就是交给 TA。绳子和卡片之间的空白处点得到下面的软件；再点一次圆钮、按 Esc 或者点到别的软件就收起。
- **大窗口里的进程视图**：每个执行者一条泳道，把卡片拖到别的泳道就是交给 TA。

## 侧边栏

Baton 平时只是贴在屏幕右边的一个细把手，彩色小点是各个任务。

- **鼠标碰到把手**就弹出侧边栏，移开自动收回；点右上角的图钉可以一直展开。
- 顶部切换「项目 / 月历」。
- 把手上方的**小圆钮**放下晾衣绳，看谁在做什么（见上面「视图」）。侧边栏右上角同样的图标、有 AI 在跑时的「看进程 →」也一样。
- 把文字从任何软件**拖到把手、任务卡或任务里**，就新建一个子任务，拖进来的文字就是它的提示词；拖到某个子任务上，就变成它的子子任务。
- 提示词旁的小复制图标**点一下复制，按住可以直接拖进 ChatGPT / Claude 的输入框**。
- **点一下文字就能改，双击就复制**（标题、提示词），原地冒出「✓ 已复制」。
- 子任务左边的节点点一下就切到下一个状态；右边的头像点一下可以换执行者，鼠标移上去还会出现「＋」（加子子任务）和「×」（删除）。
- 把手底部的小点可以按住上下拖动换位置；贴左边还是右边、要不要悬停展开，在设置里改。
- 想做细一点的编辑，点右上角 ⤢ 打开大窗口。

## 让 AI 操控 Baton（MCP）

Baton 运行时会在本机开一个 MCP 服务（`http://127.0.0.1:47821/mcp`，只有这台电脑能访问，要带密钥）。在「设置 → 让 AI 操控 Baton」里点**「一键加到 Claude Code」**，就把 Baton 加到了 Claude Code（所有项目里都能用，新开的会话生效）。Baton 会自己找 `claude` 命令行，系统里没装的话就用桌面版 Claude 自带的那个。

也可以复制设置页里的命令，自己在终端运行：

```bash
claude mcp add --transport http --scope user baton http://127.0.0.1:47821/mcp --header "Authorization: Bearer <设置页里的密钥>"
```

之后就可以直接对 Claude 说「把这个记到 Baton」「帮我把这个任务拆成子任务」「S2 做完了，标一下」「把 S3 排到周五」。AI 改了什么，侧边栏会立刻刷新并弹出提示。

AI 能用的工具：`list_projects`、`get_task`、`search`、`process_board`、`calendar`（查看），`create_project`、`create_task`、`update_task`、`add_subtasks`、`update_subtask`（新建和修改，包括把子任务排到某天），`delete_subtask`（删除子任务）。删除任务和项目只能在 Baton 里手动操作。

## 全局快捷键

关掉大窗口后 Baton 仍在侧边和菜单栏运行，快捷键在任何软件里都能用：

| 快捷键 | 作用 |
|---|---|
| `⌃⌥D` | 展开 / 收起侧边栏 |

点菜单栏图标能看到正在跑的 AI 子任务，点一下直接跳到对应任务。

## 安装依赖

```bash
npm install
```

如果 Electron 下载失败（需要走代理时），用：

```bash
ELECTRON_GET_USE_PROXY=1 GLOBAL_AGENT_HTTPS_PROXY=http://127.0.0.1:7890 npm install
```

## 开发

```bash
npm run dev
```

用单独的数据目录开发，不影响日常数据：

```bash
BATON_DATA_DIR=/tmp/baton-dev npm run dev
```

## 打包成 App

```bash
npm run build:mac
```

生成 `dist/mac-arm64/Baton.app`，拖进「应用程序」文件夹即可。自用版本没有签名，首次打开如果被拦截，在 Finder 里右键 → 打开。

## 数据

全部存在本机 `~/Library/Application Support/Baton/`：`baton.db`（SQLite）和 `settings.json`。第一版的「线程 / 步骤」数据会在启动时自动迁移成「任务 / 子任务」，放进「未分组」项目。

## 项目结构

```
src/
  main/       主进程：侧边栏和把手窗口、大窗口、菜单栏、快捷键、数据库、MCP 服务
  preload/    主进程和界面之间的桥
  renderer/   界面（React）；board/ 是项目视图、进程视图、子任务路线，dock/ 是侧边栏和把手
  shared/     两边共用的类型、执行者、提示词展开逻辑
resources/    菜单栏图标
scripts/      生成图标的脚本
```
