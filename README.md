# Baton

![platform](https://img.shields.io/badge/platform-macOS-lightgrey) ![license](https://img.shields.io/badge/license-MIT-blue)

AI 时代的多线程任务接力工具。

同时推进好几件事、在多个 AI 和软件之间来回切换时，用它记住每个任务**做到哪、下一步做什么、提示词怎么写、交给了谁、哪天做**。它常驻在屏幕边上，点一下就展开，不打断手上的事。

> A macOS sidebar for juggling many AI-assisted tasks at once: projects → tasks → subtasks, each with its own prompt, status, assignee (Claude / Codex / Muse / you) and date. Includes a top-of-screen "clothesline" of in-progress tasks, a month calendar, a dashboard with a workload heatmap, and an MCP server so Claude Code can read and update your tasks. The UI is in Chinese.

## 它能做什么

- **贴在屏幕边上的侧边栏**：平时只是一个细把手，点一下展开；把任何软件里的文字拖上来就是一个新的子任务。
- **项目 → 任务 → 子任务 → 子子任务**：每一层都能写提示词，点一下就地编辑、双击复制，也能直接拖进 AI 的输入框。
- **接力 / 独立**：子任务可以接在上一个后面（上一个做完才轮到它），也可以独立随时做。
- **进度状态**：待办 / 进行中 / 已暂停 / 已完成，上一层跟着下一层自动汇总；谁在做（Claude、Codex、Muse、我）只是旁边的小头像。
- **晾衣绳**：屏幕顶上垂下一根绳子，进行中的任务一张张夹在上面，卡片里就能管理整个任务；待办、暂停、今天完成的记在便签上。
- **日期和月历**：每个子任务都有「哪天做」，新建默认今天；月历里拖动排日子、直接在某天加东西。
- **总看板**：一排关键数字、日程热力图（一眼看出哪几天忙）、项目进度、谁手上有活、每周完成、逾期和接下来 7 天。
- **让 AI 直接操控**：内置 MCP 服务，在 Claude Code 里说「把这个记到 Baton」「S2 做完了」「把 S3 排到周五」就行。
- **数据都在本机**：一个 SQLite 文件，不联网、不上传。

## 安装

### 直接下载（推荐）

到 [Releases](https://github.com/Lyra-GongYingli/baton/releases/latest) 下载对应的压缩包：

| 你的 Mac | 下载 |
|---|---|
| Apple 芯片（M1 / M2 / M3 / M4…） | `Baton-版本号-mac-arm64.zip` |
| Intel 芯片 | `Baton-版本号-mac-x64.zip` |

不确定是哪种？点屏幕左上角  → 关于本机，看「芯片」一栏写的是 Apple 还是 Intel。需要 macOS 12 或更新。

1. 双击压缩包解压，把 `Baton.app` 拖进「应用程序」文件夹。
2. 第一次打开：这个 App 没有做苹果公证，系统会提示「无法验证开发者」，按下面放行一次，以后就能正常打开：
   - **macOS 15 及以后**：双击打开 → 提示框点「完成」→ 打开「系统设置 → 隐私与安全性」，往下拉，在 Baton 那一行点「仍要打开」。
   - **macOS 14 及以前**：在「应用程序」里**右键** Baton → 打开 → 在提示框里点「打开」。
   - 或者在终端运行一次：`xattr -dr com.apple.quarantine /Applications/Baton.app`
3. 打开后屏幕右边会出现一个细把手，点一下就开始用。

### 从源码打包

需要 **Node.js 22 或更新**。

```bash
git clone https://github.com/Lyra-GongYingli/baton.git
cd baton
npm install
npm run build:mac
```

打包好的 App 在 `dist/mac-arm64/Baton.app`（Apple 芯片）或 `dist/mac/Baton.app`（Intel），拖进「应用程序」文件夹，双击打开。

如果 `npm install` 时下载 Electron 失败（网络需要代理），设置代理后再装：

```bash
ELECTRON_GET_USE_PROXY=1 GLOBAL_AGENT_HTTPS_PROXY=http://你的代理地址:端口 npm install
```

## 快速上手

1. 打开 Baton 后，屏幕右边会出现一个细把手。**点一下把手**展开侧边栏。
2. 已经有一个「我的项目」了（点名字可以改名），点它旁边的「＋」加一个任务；想分开管理可以再点「新项目」。
3. 点进任务，在底部「加一个子任务」写下第一步，回车；点提示词那一栏写给 AI 的提示词。
4. 要用的时候**双击提示词就复制**，或者按住右上角的小图标直接拖进 ChatGPT / Claude 的输入框。
5. 点把手上方的小圆钮，屏幕顶上会垂下晾衣绳，看所有进行中的任务。

## 使用说明

### 结构

**项目 → 任务 → 子任务 → 子子任务**

**状态**：三层共用一套状态，只表达进度——**待办 / 进行中 / 已暂停 / 已完成**。每一行都有一个状态标签，点开就能换；谁在做（Claude、Codex、Muse、我）只是旁边的小头像，换人不会改状态。上一层的状态**跟着下一层自动走**（任务跟子任务，子任务跟子子任务）：都没开始不动，有进行中、已暂停或完成了一部分是进行中，全部完成是已完成；已暂停是手动设的，不会被自动改。把某一层标成已完成时，下面的会一起完成。

- **项目**：一块大的事，比如「个人网站」。第一次打开 Baton 会先有一个「我的项目」可以直接用。点名字可以改名，点色块可以换颜色；鼠标移到项目标题上会出现垃圾桶，点了确认一下就能删掉这个项目（连同里面的任务）。
- **任务**：项目里要推进的一件事，有自己的提示词和状态。里面是一个子任务 list。
- **日期**：每个子任务都有「哪天做」，**新建时默认是今天**（侧边栏、晾衣绳、大窗口、拖文字进来、AI 加的都一样）。子任务那一行的日期标签（今天 / 明天 / 10/25，逾期标红，没排的是「未安排」）点一下就能改：今天、明天、后天、下周一，或者在小月历里点任何一天，也可以清除放回「待安排」。**任务卡片右下角是当前那个子任务哪天做**，点一下就能改；后面还有排得更晚的会跟一个「→ 10/28」，告诉你整个任务排到哪天。月历里每一天都可以直接加东西：点格子右上角的「＋」或者「＋ 加到这天」，写个标题、选加到哪个任务（默认当前任务），也可以顺手新建一个任务。
- **子任务**：任务里的具体一步，编号 S1、S2…（排序变了编号也不变），带一段提示词，可以分给一个执行者：**Claude、Codex、Muse，或者你自己（猫咪）**。左边的节点点一下切到下一个状态（待办 → 进行中 → 已完成）。
  - **接力子任务**：圆形节点，和上一个用实线连着，上一个完成后才轮到它（没完成时显示「等 Sx 完成」）。
  - **独立子任务**：方形节点，和上一个断开，随时可以做。
  - 两个子任务之间的连接处点一下，就能接上或断开。
- **子子任务**：挂在子任务下面的清单（S1.1、S1.2…），状态 + 标题 + 提示词。左边的小方块点一下切到下一个状态，右边的标签点开随便换。子任务右侧的「＋」可以连续加。
- **拖动换位置**：子任务和子子任务都能按住拖。上下拖换位置；拖的时候**往右挪**就放进上面那个子任务、变成它的子子任务，**往左挪**就提出来变成子任务（会拿到新的 S 编号）。带着子子任务的子任务拖动时，子子任务跟着走，但它不能再被放进别的子任务里（最多两层）。拖动时有一条插入线，告诉你松手后落在哪一层。
- **提示词**：每一层都能写，点一下就地编辑，双击复制；右上角的小图标点一下也能复制，按住还能直接拖进 AI 的输入框。可以写 `{{目标}}`，复制时换成任务目标。

### 视图

- **总看板**（大窗口的首页）：所有项目放在一起看。最上面一排数字（进行中的任务和子任务、本周安排、本周完成、逾期）；**日程热力图**一格一天、颜色越深越忙，可以切换看「安排了几件」还是「完成了几件」，旁边列出最忙的几天，点任何一天就在月历里打开那天；下面是每个项目的进度条（已完成 / 进行中 / 已暂停 / 待办 各几个）、谁手上有活、最近 12 周每周完成几个、逾期和接下来 7 天要做的。
- **项目视图**：项目一组一组排开，任务卡夹在洞洞板上。项目、任务都能按住拖动排序，任务可以拖到别的项目里。
- **月历**（侧边栏的第二个标签，大窗口里也有一个更大的）：子任务安排在哪天做。上面是一个月的格子，每天显示排在这天的子任务（项目颜色 + 标题，做完的划掉）；点一天，下面列出这天的子任务，再下面是还没排日子的「待安排」。**按住拖到某一天就排到那天**，格子里的条也能拖到别的日子，拖回「待安排」就取消安排。清单里点一下打开任务，双击复制提示词。
- **晾衣绳（进程）**：点把手上方的小圆钮（侧边栏开着时点右上角同样的图标），屏幕顶上会垂下一根绳子。**主角是进行中的任务**：每个任务一张卡片，里面就是侧边栏的任务页（紧凑版）——改标题、目标、任务提示词，加 / 删 / 拖动子任务和子子任务，接上或断开接力，换状态、换人，复制提示词，和在侧边栏里一样；内容多了在卡片里滚动。**待办 / 已暂停 / 今天完成** 的任务记在最左边的一张黄色便签上，当辅助信息：每一栏全部列出来，点栏目标题可以折起 / 展开（会记住），任务多了便签里面可以滚动。
  - **右击换状态**：右击任务卡片（空白处或标题）、便签上的任务，弹出 待办 / 进行中 / 已暂停 / 已完成；改成不是进行中的，卡片就回到便签上。右击卡片里某个子任务或子子任务，只改它自己。
  - **拖动**：按住卡片最上面那一条拖到便签的某一栏，任务就改成那个状态；从便签上把任务拖到绳子上，就开始做（变成进行中）。点便签上的任务会在侧边栏打开它。
  - 绳子和卡片之间的空白处点得到下面的软件；再点一次圆钮、按 Esc 或者点到别的软件就收起。
  - **双击圆钮就固定住**：晾衣绳一直挂着，不抢焦点，点别的软件、按 Esc 也不收，重启 Baton 后还在；圆钮右上角会多一颗小黄点，便签上有个 📌。再双击圆钮、或者点便签上的 📌 取消固定，单击圆钮直接收起。
- **大窗口里的进程视图**：按状态分四列，把卡片拖到另一列就是改状态。

### 侧边栏

Baton 平时只是贴在屏幕右边的一个细把手，彩色小点是各个任务。

- **点一下把手**弹出侧边栏，点别的地方、按 Esc 或者 `⌃⌥D` 收起；点右上角的图钉可以一直展开。
- 侧边栏、晾衣绳在每个桌面（Space）和全屏 app 上都能用，点开不会把你拽回别的桌面；从侧边栏打开的大窗口也出现在你当前所在的桌面。
- 顶部切换「项目 / 月历」。
- 把手上方的**小圆钮**放下晾衣绳，看谁在做什么。侧边栏右上角同样的图标、有子任务进行中时的「看进程 →」也一样。
- 把文字从任何软件**拖到把手、任务卡或任务里**，就新建一个子任务，拖进来的文字就是它的提示词；拖到某个子任务上，就变成它的子子任务。
- **点一下文字就能改，双击就复制**（标题、提示词），原地冒出「✓ 已复制」。
- 子任务左边的节点点一下就切到下一个状态，**右击子任务、子子任务或任务卡片可以直接选状态**；头像点一下可以换执行者，鼠标移上去还会出现「＋」（加子子任务）和「×」（删除：点一下变成「删除？」，再点一下才删）。
- 把手底部的小点可以按住上下拖动换位置；贴左边还是右边，在设置里改。
- 想做细一点的编辑，点右上角 ⤢ 打开大窗口。

### 全局快捷键

关掉大窗口后 Baton 仍在侧边和菜单栏运行，快捷键在任何软件里都能用：

| 快捷键 | 作用 |
|---|---|
| `⌃⌥D` | 展开 / 收起侧边栏 |

点菜单栏图标能看到进行中的子任务，点一下直接跳到对应任务。

## 让 AI 操控 Baton（MCP）

Baton 运行时会在本机开一个 MCP 服务（`http://127.0.0.1:47821/mcp`，只有这台电脑能访问，要带密钥）。在「设置 → 让 AI 操控 Baton」里点**「一键加到 Claude Code」**，就把 Baton 加到了 Claude Code（所有项目里都能用，新开的会话生效）。Baton 会自己找 `claude` 命令行，系统里没装的话就用桌面版 Claude 自带的那个。

也可以复制设置页里的命令，自己在终端运行：

```bash
claude mcp add --transport http --scope user baton http://127.0.0.1:47821/mcp --header "Authorization: Bearer <设置页里的密钥>"
```

之后就可以直接对 Claude 说「把这个记到 Baton」「帮我把这个任务拆成子任务」「S2 做完了，标一下」「把 S3 排到周五」。AI 改了什么，侧边栏会立刻刷新并弹出提示。

AI 能用的工具：`list_projects`、`get_task`、`search`、`process_board`、`calendar`（查看），`create_project`、`create_task`、`update_task`、`add_subtasks`、`update_subtask`（新建和修改，包括把子任务排到某天），`delete_subtask`（删除子任务）。删除任务和项目只能在 Baton 里手动操作。

其他支持 MCP（Streamable HTTP）的工具也能连：地址同上，请求头 `Authorization: Bearer <密钥>`。

## 数据与隐私

- 所有数据都存在本机 `~/Library/Application Support/Baton/`：`baton.db`（SQLite）和 `settings.json`。不联网、不上传、没有统计。
- MCP 服务只监听 `127.0.0.1`，别的电脑连不上；每次请求都要带上设置页里那串随机生成的密钥。
- 想备份或换电脑，复制上面那个文件夹就行。

## 开发

```bash
npm install
npm run dev
```

用单独的数据目录开发，不影响日常数据：

```bash
BATON_DATA_DIR=/tmp/baton-dev npm run dev
```

类型检查和打包：

```bash
npm run typecheck
npm run build:mac
```

技术栈：Electron + React + TypeScript（electron-vite），数据库用 Node 自带的 `node:sqlite`，拖动用 dnd-kit，MCP 用官方的 `@modelcontextprotocol/sdk`。

### 项目结构

```
src/
  main/       主进程：侧边栏、把手、晾衣绳、大窗口、菜单栏、快捷键、数据库、MCP 服务
  preload/    主进程和界面之间的桥
  renderer/   界面（React）
    board/      项目视图、进程视图、任务正文、子任务路线
    dock/       侧边栏、把手、月历
    line/       晾衣绳
    views/      大窗口的总看板、任务页、设置
    components/ 状态标签、日期选择、右键菜单等小部件
  shared/     两边共用的类型、执行者、日期、提示词展开逻辑
resources/    App 图标、菜单栏图标
scripts/      生成图标的脚本（App 图标：npx electron scripts/make-app-icon.mjs）
```
